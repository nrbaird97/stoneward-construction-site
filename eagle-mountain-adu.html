Eagle Mountain, Utah County

Eagle Mountain already allows detached ADUs, and is updating them.

Eagle Mountain's city code has allowed detached accessory dwelling units for years, and city planners told us they are preparing an amendment for Utah's SB 284. They also said state code supersedes city code and applies now. The existing numbers are a starting point, not the final word.

What we confirmed for Eagle Mountain

Source: Eagle Mountain Municipal Code Chapter 17.70 (Ord. O-41-2021 and amendments); email reply from Eagle Mountain planning staff in November 2026; Utah Code 10-21-304.

Official text: Eagle Mountain code, Chapter 17.70 (Accessory Dwelling Units)

Existing code
Chapter 17.70 allows an ADU inside, attached to, above a garage, or in a separate detached structure on a single-family lot
Size (existing)
Detached ADU living space of 400 sq ft minimum and 1,200 sq ft maximum, no more than two bedrooms
Height (existing)
Above a garage, 35 ft. Standalone units, no more than two stories and 35 ft
Setbacks (existing)
Same front, side and rear setbacks as the main home, and at least 6 ft from the main home
Frontage (existing)
70 ft of street frontage, with discretion for unusual lots
Parking (existing)
Two off-street spaces on a hard surface. State law now caps parking at 1 under 650 sq ft and 2 at 650 or more
Application
Planners say there is no DADU-specific application; use the ADU application and specify the type
Status
Amendment for SB 284 in preparation. State code applies in the meantime

Not confirmed: Which existing standards will survive the SB 284 amendment, in particular the 2 space parking rule, the 400 sq ft minimum and the 70 ft frontage rule. Confirm with Eagle Mountain planning before you design.

About Eagle Mountain

A fast-growing city with a head start.

Eagle Mountain is a young, fast-growing city on the west side of Utah Lake in northwest Utah County, with the Lake Mountains between it and Saratoga Springs. Large new subdivisions, wide streets and newer homes define much of it, so backyards tend to be open, level and easy for a crane to reach.

What sets Eagle Mountain apart is that it did not start from zero this fall. City code already described a detached ADU on a permanent foundation, with a 400 square foot minimum, which excludes the smallest cabins. The city says state law now overrides any conflicting standard, so use the existing code as a guide and confirm the final rules with the planning department.

What it means for you

What this means for a Eagle Mountain homeowner.

Already allowed

Detached units, including a cottage or casita, are part of Chapter 17.70, so there is a track record at the permit counter.

A 400 square foot floor

The existing code sets a minimum living space of 400 square feet, which rules out the smallest studio plans.

One ADU, owner on site

The existing code allows one ADU per lot and expects the owner to live in the main home or the ADU.

State law now overrides

Planners said state code supersedes city code and applies now, so parking and other limits may be lighter than the printed code.

Getting it built in Eagle Mountain

From a Eagle Mountain lot to move-in.

The full process
  1. Read Chapter 17.70. Then ask Eagle Mountain planning which parts the SB 284 amendment will change.
  2. Check the lot. Confirm frontage and where the unit can sit, six feet from the house.
  3. Choose a plan. At least 400 square feet and no more than two bedrooms.

  5. Site work, set and finish. Foundation and utilities, crane day, then finish work.

Questions

Eagle Mountain ADU questions, answered.

Does Eagle Mountain allow detached ADUs?

Yes. Chapter 17.70 of the city code allows an ADU in a separate detached structure or above a detached garage on a single-family lot, where the zone permits it. Planners say an amendment for SB 284 is being prepared.

Is there a separate application for a detached ADU?

City planners told us there is no DADU-specific application, only an ADU application in which you specify the type.

How big can it be?

Existing code sets a minimum of 400 and a maximum of 1,200 square feet of living space, with no more than two bedrooms. Confirm the numbers against the amendment.

How much parking is required?

The printed code says two off-street spaces. State law now caps parking at one space for a unit under 650 square feet and two at 650 or more, and planners say state code applies now.

Do I have to live on the property?

Existing code says the owner should live in the main home or the ADU, except for bona fide temporary absences.

Can it have its own utility meters?

Yes. The existing code says a detached ADU may have separate utility meters, with all municipal utilities in the owner name.

General information, not legal advice. Cities can amend their ordinances, so confirm current rules with Eagle Mountain before you design or buy.
