About West Point

West Davis County, where the lots run level.

West Point is in west Davis County, near Clinton, Syracuse and Layton, toward the Great Salt Lake. Much of the city sits on level ground with newer subdivisions, and the West Davis Corridor has changed how people reach it. Flat lots make site work simpler than on a foothill bench.

West Point's current rules are specific: an ADU must have an owner-occupant on the property, and detached ADUs need a permanent foundation and cannot have a basement. A factory-built unit set on a permanent foundation lines up with that, and the October 13 council agenda shows the city is rewriting the section for SB 284, so check the current text.

What it means for you

What this means for a West Point homeowner.

Permanent foundation

Modular units are set on a permanent foundation, which matches the city's detached ADU standard.

No basement

The current code does not allow basements in detached ADUs, which is how most modular ADUs are built.

Owner occupancy

Questions

West Point ADU questions, answered.

Does West Point allow detached ADUs?

West Point's current code allows ADUs with specific standards, including an owner-occupant on the property, a permanent foundation and no basements for detached units. The council took up Ordinance 569 on accessory dwelling units on October 13, 2026 as SB 284 requires. We could not confirm the outcome.

Do I need to live on the property?

The current code allows an ADU only with an owner-occupant living on the property.

Can a detached ADU have a basement?

Not under the current code, which does not allow basements in detached ADUs.

What lot size do I need?

State law requires covered cities to allow a detached ADU on lots of 11,000 square feet or more. Confirm West Point's final text.

Is a modular unit allowed on a permanent foundation?

Yes. Modular homes are built to the residential code and set on a permanent foundation.

General information, not legal advice. Cities can amend their ordinances, so confirm current rules with West Point before you design or buy.
